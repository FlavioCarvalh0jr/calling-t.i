# Roadmap do Calling T.I.

## Concluído

- [x] Cadastro e consulta de chamados com SQLite.
- [x] Consulta de chamados por solicitante entre execuções.
- [x] Geração de códigos a partir do ID do SQLite.
- [x] Data e hora calculadas a cada abertura.
- [x] Validação de campos obrigatórios no terminal.
- [x] Separação dos arquivos de estudo e das cópias de segurança.

- [x] Fixar o caminho do banco em relação ao arquivo principal.
- [x] Permitir que o técnico atualize o status do chamado.

## Próximas etapas sugeridas

- [ ] Separar acesso ao banco, regras e menus em pequenas etapas.
- [ ] Criar testes automatizados com banco isolado.
- [ ] Atualizar a documentação com capturas reais do terminal.

## Versão web futura

- [ ] Confirmar a escolha de Flask, Jinja, HTML e CSS, mantendo SQLite.
- [ ] Criar páginas de listagem, abertura e detalhes.
- [ ] Adicionar filtros e resumo dos chamados.
- [ ] Implementar autenticação e permissões de usuário e técnico.
- [ ] Preparar layout responsivo e demonstração para o portfólio.

Cada etapa será discutida e implementada gradualmente.
