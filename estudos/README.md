# Estudos

- `testes_main.py`: versão antiga de estudo, com suas edições preservadas. Não é uma suíte de testes automatizados e não contém as correções atuais de `main.py`.
- `exercicios`: arquivo vazio reservado para exercícios.

Para executar o sistema atualizado, use `python main.py` na raiz do projeto.

O script antigo utiliza `calling.db` relativo à pasta de execução. Para experimentá-lo, execute em uma pasta separada com um banco de teste, evitando gravar no banco principal.
